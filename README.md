# Caderno de Trauma — UNIFESP 2027

Repositório privado do caderno de estudos de trauma.

## Privacidade
Este repositório deve permanecer **privado**. O site completo inclui material de estudo e imagens de referências que não devem ser publicados na web aberta.

**Não ativar GitHub Pages público.** A publicação privada será configurada separadamente com autenticação (Cloudflare Access ou serviço equivalente), permitindo acesso somente a duas contas autorizadas.

Arquivo principal previsto: `index.html` (caderno interativo).

## Atualizações
Cada novo tema concluído substituirá `index.html` mantendo o mesmo endereço do site protegido. Verificar o controle de acesso antes de habilitar qualquer deploy.
